# D-01: בדיקת העיצוב

הצילומים נמצאים בתיקיית העבודה של D-01, תחת `shots/`. הגלריה מציגה דוגמאות בשתי השפות; היא כלי בדיקה ולא מסך למשתמשים.

## מה חדש ואיפה

- כפתור בזמן טעינה שומר על המילים לצד הסימן, וכפתור מושבת קריא יותר. לפני: `baseline/gallery-he-light-375-full.png`; אחרי: `after/gallery-he-light-375-full.png`.
- כפתור ההוספה המהירה מקבל צבע פעולה והחץ בתוכו. לפני ואחרי: אותם צילומים.
- פעולת הביטול בהודעה נראית כמו קישור שקט; באנגלית היא נקראת Undo. צילום אחרי במגע: `run2-toast-he-375.png` ו־`run2-toast-en-375.png`.
- בכפתורי האייקון בגלריה מופיע אייקון מתוך ערכת האייקונים במקום תו טקסט. האיור מקבל מסגרת מעוגלת ורקע שמתמזג עם הדף הבהיר. לפני: `baseline/gallery-he-light-375-full.png`; צילום איור מעודכן: `run2-illustration-light-375.png`; במצב כהה נותרת מסגרת בהירה: `run2-illustration-dark-375.png`.
- הגלריה זמינה גם בשרת פיתוח מקומי, ונשארת חסומה בייצור.

|---|---|---|
| Button, טעינה | הסימון החליף את המילים ולכן הפעולה לא הייתה ברורה. המילים נשארות לצד הסימון. | `baseline/gallery-he-light-375-fold.png` |
| Button, מושבת | שקיפות החלישה את הניגודיות. הוחלפה במשטח וטקסט מתוך הטוקנים. | `baseline/gallery-en-dark-1280-fold.png` |
| QuickAdd | כפתור השליחה נראה כעיגול ללא פעולה ברורה. ניתן לו צבע פעולה עם החץ בתוכו. | `baseline/gallery-he-light-375-full.png` |
| Toast | ביטול נראה ככפתור כהה וקטן. הוחלף למראה קישור עם שטח לחיצה 44 פיקסלים. | ממצא סקירת P-03; אחרי: `run2-toast-he-375.png` |

| Gallery | שרת פיתוח מקומי לא פתח את הגלריה. נוסף אישור לפיתוח, לאחר חסימה מפורשת של ייצור. | בדיקת שער הגלריה |
| Field | בדוגמאות אין טקסט לדוגמה בתוך כל שדה. יש להוסיף דוגמאות מתורגמות בגלריה בהמשך, תוך שמירה על משמעות כל שדה. | `baseline/gallery-he-light-375-full.png` |
| EmptyState | הדוגמאות משתמשות בסימן טקסט במקום איור שמסביר את המצב. יש לבחור איור מתאים בחוזה תוכן הגלריה. | `baseline/gallery-he-light-375-full.png` |
| HelpTip | בצילום הסגור אי אפשר לבדוק את ההסבר הפתוח. יש לצלם ולבדוק פתיחה במגע ובמקלדת בחוזה המשך. | `baseline/gallery-he-light-375-full.png` |
| Sheet ו-Dialog | הצילום מציג רק כפתורי פתיחה. החלונות הפתוחים צולמו; בדיקת סגירה ומיקוד עדיין נדרשת בחוזה המשך. | `run2-dialog-he-375.png`, `run2-sheet-he-375.png` |
| Shell | הגלריה אינה מציגה את סרגלי הניווט. נדרש צילום ובדיקה נפרדים של המעטפת עם נתוני דמה. | לא צולם |

## דורש חוזה המשך

השדות, דוגמאות המצבים הריקים, בדיקת ההסברים והחלונות הפתוחים, והמעטפת מפורטים בטבלה. רקע האיורים במצב כהה עדיין מסגרת בהירה: שקיפות אמיתית מחייבת עיבוד של קובצי הנכסים, שאינם בבעלות חוזה זה. בבדיקת מגע מדומה בגלריה תווית הביטול הופיעה בשפה הנכונה בשתי השפות. עדיין נדרשת בדיקה במכשיר אמיתי, משום שהתווית מסתמכת על שפת הרכיב הממוקד או המסמך. הצילומים הקיימים אינם מהווים אישור נגישות מלא.
