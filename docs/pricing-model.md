## 1. עקרונות מנחים

### האתגר

בית בסדר מתחרה באפליקציות **חינמיות לחלוטין** בשוק הישראלי. רוב הזוגות לא חושבים שהם "צריכים" לשלם על ניהול בית — עד שהם מתחברים לאפליקציה ומרגישים את הכאב של החיים בלעדיה.

### שלושה עקרונות

**1. "כלל 60/40" — הבסיס לא חינמי, הוא שכר לימוד**
החינמי הוא לא "גרסה מוגבלת" — הוא ה-demo. הוא צריך להיות מספיק טוב כדי שמשתמשים *ירצו* להישאר, ומספיק מוגבל כדי שהם *ירצו* לשדרג.

**2. הגבולות מבוססים על ערך, לא על כאב מלאכותי**
לא לחסום פיצ'רים שכולם מצפים שיהיו (כמו D&D בסיסי). לחסום פיצ'רים שמוסיפים ערך אמיתי: AI, ניתוח נתונים, תבניות מתקדמות.

**3. תמחור למשק בית — לא לאדם**
זוג משלם פעם אחת. זה מה שמייחד את בית בסדר מ-SaaS רגיל — ה-unit של הערך הוא הבית, לא האדם.

### 🏠 הבית — חינם לנצח

> "מספיק כדי להתחיל, מספיק כדי להתמכר"

**מחיר:** ₪0 לנצח. ללא כרטיס אשראי. ללא הגבלת זמן.

**מה כלול:**
- עד **25 משימות** (יותר מ-15 בגלל שישראלים רגישים למגבלות קשות)
- **2 משתמשים** (הקונספט המרכזי תמיד נשמר)
- **רשימת קניות** בסיסית — עד 50 פריטים, קטגוריות ברירת מחדל
- **תוכנית שבועית ידנית** — D&D, שיבוץ ידני
- **סטריק ורמה** — המונה הבסיסי (ממכר!)
- **8 קטגוריות משימות** ברירת מחדל
- **התראות Push** בסיסיות (אפשר לכבות)
- **מצב כהה / בהיר** — תמיד חינם (UX בסיסי)

**מה לא כלול:**
- AI coaching ותכנון חכם
- חלוקה אוטומטית (Wizard)
- סטטיסטיקות מפורטות
- מצבים עונתיים (פסח, חנוכה, קיץ)
- קטגוריות מותאמות אישית
- הישגים ובאדג'ים (מעבר ל-5 הבסיסיים)
- WhatsApp reminders
- ייצוא נתונים

### ✨ בית בסדר+ — הלב של המוצר

> "בית שמנהל את עצמו"

**מחיר:** ₪15/חודש | ₪120/שנה (= **₪10/חודש — חיסכון של ₪60!**)

**מה כלול — הכל מ"הבית" ובנוסף:**

**AI ותכנון חכם:**
- **Wizard אוטומטי** — חלוקת משימות שבועית בלחיצה אחת
- **AI Coaching** — טיפים יומיים מותאמים אישית (מופעל ע"י Gemini)
- **תוכנית עונתית** — מצב פסח (37 משימות), מצב קיץ, חנוכה (יתווספו)
- **Zone Scheduling** — "ראשון: מטבח + אמבטיה, שני: סלון + חדרים"

**נתונים וניתוח:**
- **סטטיסטיקות מלאות** — מי עושה מה, מגמות, לאורך זמן
- **יחס הזהב** + טרנד שבועי
- **לוח שנה** — תצוגה חודשית של כל המשימות
- **ייצוא לאקסל/CSV**

**גיימיפיקציה מלאה:**
- **כל 24 ההישגים** + badges
- **14 אתגרי שבוע**
- **לוח מובילים** (בין שני בני הזוג)
- **קבלות מותאמות אישית** (אנימציות confetti לפרימיום)

**תקשורת ושיתוף:**
- **WhatsApp reminders** — תזכורות + Reply-to-complete
- **שיתוף רשימת קניות** ב-WhatsApp
- **ייצוא PDF** לתוכנית השבוע

**ניהול מתקדם:**
- **משימות ללא הגבלה**
- **קטגוריות מותאמות אישית** (לא רק ברירת מחדל)
- **רשימות קניות מרובות** + היסטוריה
- **תבניות משימה** + משימות מותאמות
- **ללא מודעות** (אם נחליט על מודל פרסום בחינם)

**מה כלול — הכל מ"בית+" ובנוסף:**

- **הקצאה חכמה לפי גיל** בחלוקה האוטומטית
- **דוחות משפחתיים** — ביצועי כולם לאורך זמן
- **שיעורי בית לחיים** — ספרייה של 50+ משימות מותאמות לילדים

## 4. נימוק לבחירת הפיצ'רים

### למה 25 משימות חינם (ולא 15 או 10)?

בית ממוצע בישראל מנהל 30–60 משימות חוזרות. 25 זה מספיק לחוות את האפליקציה בצורה מלאה לחודש-חודשיים, אבל בית "מסודר" יגיע לתקרה ויתסכל. זה בדיוק איפה שאנחנו רוצים אותם — מבינים את הערך, חשים את ה-friction.

**לא 15** — זה מרגיש כמו הגבלה מלאכותית ויפגע בחוויה.
**לא 50** — אז אין סיבה לשדרג.

### למה ה-Wizard האוטומטי הוא Feature Gate העיקרי?

זה ה-"wow moment" של האפליקציה. כשמשתמש מגלה שבלחיצה אחת יש לו תוכנית שבוע עם חלוקה הוגנת — זה הרגע שהוא מבין למה הוא משלם.

נוסף על כך: הוא דורש Gemini API, שיש לו עלות — מה שמצדיק כלכלית לשים אותו בפרימיום.

### למה סטטיסטיקות בתשלום?

כי "מי עושה יותר בבית?" הוא אחד הוויכוחים הזוגיים הנפוצים ביותר. נתונים מדויקים = ערך רגשי + פרקטי. זה בדיוק הפיצ'ר שאנשים *ישמחו לשלם* עליו.

### למה AI Coaching בתשלום?

עלות תפעולית ישירה (Gemini API). בנוסף: זה פיצ'ר שמשתמש חדש לא מבין עד שהוא רואה אותו. שים את ה-coaching בפרימיום, הצג "preview" בחינם (טיפ אחד ראשון בחינם, שאר מאחורי paywall).

### למה מצב כהה תמיד חינם?

כי לנעול מצב כהה ב-2026 זה aggressive ומעצבן. זה גורם לאנשים לדבר עלייך ברשת *לרעה*. תן UX בסיסי חינם — תגבה על ערך.

### למה "בית משפחה" כשלב 3?

כי ניהול ילדים הוא מוצר אחר. הוא דורש:
- פיצ'רים ייחודיים (אישורי הורה, נקודות כיס)
- יותר מ-2 משתמשים = עלות תפעולית גבוהה יותר
- קהל יעד שמוכן לשלם יותר

**חשוב:** "בית משפחה" לא בהכרח לשים בגרסה 1. אפשר להתחיל עם שתי שכבות ולהוסיף את המשפחה כשיש מספיק משתמשים.

## 6. הערות טכניות — מה צריך גייטינג

| **Wizard gate** | לא קיים | עטוף ב-`canAccess('wizard')` |

| **Seasonal gate** | לא קיים | עטוף ב-`canAccess('seasonal')` |
| **Multi-user (6)** | לא קיים | logic קיימת, צריך tier check |
| **Subscription DB** | לא קיים | טבלה `subscriptions` בסופאבייס |

### סכמת DB מינימלית

```sql
-- טבלת מנויים
CREATE TABLE subscriptions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  household_id UUID REFERENCES households(id),
  tier TEXT NOT NULL DEFAULT 'free', -- 'free' | 'plus' | 'family'
  status TEXT NOT NULL DEFAULT 'active', -- 'active' | 'canceled' | 'expired'
  current_period_start TIMESTAMPTZ,
  current_period_end TIMESTAMPTZ,
  stripe_customer_id TEXT,
  stripe_subscription_id TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- RLS: כל בני משק הבית רואים את המנוי
ALTER TABLE subscriptions ENABLE ROW LEVEL SECURITY;
CREATE POLICY "household members can read their subscription"
  ON subscriptions FOR SELECT
  USING (
    household_id IN (
      SELECT household_id FROM profiles WHERE id = auth.uid()
    )
  );
```

## 7. תחזיות הכנסות

### הנחות בסיס

- שוק יעד: ~200,000 זוגות ישראלים עם סמארטפון (גיל 25–45)
- חדירה שנה 1: 0.5–1% = 1,000–2,000 משתמשים פעילים
- חדירה שנה 3: 2–5% = 4,000–10,000 משתמשים פעילים
- המרה לפרימיום: 4–8% (ממוצע ענף: 3–5%)
- ARPU שנתי: ₪130 (מעורב חודשי/שנתי, בניכוי עמלות App Store)

### תרחיש שמרני (שנה 1)

|------|-----|
| משתמשים פעילים | 500–1,000 |
| המרה לפרימיום | 3% |
| מנויים משלמים | 15–30 |
| ARPU שנתי | ₪130 |
| **הכנסה שנתית** | **₪2,000–₪4,000** |
| עלויות תפעול | ₪600–₪1,200/שנה |
| **רווח נקי** | **₪1,400–₪2,800** |

### תרחיש ריאלי (שנה 1–2)

| מדד | ערך |
|------|-----|

### Breakeven

כדי לכסות 10 שעות עבודה בחודש @ ₪150/שעה (₪18,000/שנה):
- צריך **~140 מנויים שנתיים** (₪120 x 140 = ₪16,800)
