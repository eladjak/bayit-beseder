## חלופת Git דרך ענף ו־PR

אם נדרשת חזרה בקוד במקום קידום הפריסה הישנה, פתחו ענף חדש מ־`origin/master` העדכני והריצו בו:

```sh

```

בדקו את השינוי והבדיקות המתאימות, פתחו PR ל־master ובדקו את הפריסה לאחר המיזוג. אם יש קונפליקט, עצרו ובדקו אותו; אל תפתרו בניחוש. קידום פריסה ו־revert הן חלופות נפרדות: אין לבצע אותן אוטומטית יחד. את פקודת `vercel promote` לעיל יש להריץ מהמחשב המקושר לחשבון ולפרויקט, לאחר אימותם. שתי החלופות אינן משחזרות נתוני מסד או סכמה.
