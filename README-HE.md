# בית בסדר (BayitBeSeder)

אפליקציית ניהול בית משותף לזוגות ושותפים. עברית מלאה, RTL, מותאמת למובייל עם גיימיפיקציה, תכנון שבועי חכם ואינטגרציה עם וואטסאפ.

## תכונות

- ממשק עברי מלא עם תמיכה ב-RTL
- PWA -- עובד גם אופליין
- גיימיפיקציה -- נקודות, הישגים ותחרות בריאה
- תכנון שבועי חכם עם סיוע AI
- מעקב משימות בזמן אמת
- עיצוב מותאם מובייל
- אימות משתמשים דרך Supabase

## טכנולוגיות

| טכנולוגיה | שימוש |
|-----------|-------|
| [Next.js 14](https://nextjs.org/) | פריימוורק React |
| [TypeScript](https://www.typescriptlang.org/) | בטיחות טיפוסים |
| [Supabase](https://supabase.com/) | בקאנד ואימות |
| [Tailwind CSS](https://tailwindcss.com/) | עיצוב |
| [Framer Motion](https://www.framer.com/motion/) | אנימציות |

## התקנה

```bash
git clone https://github.com/eladjak/bayit-beseder.git
cd bayit-beseder
bun install
bun dev
```

פתחו [http://localhost:3000](http://localhost:3000) בדפדפן.
